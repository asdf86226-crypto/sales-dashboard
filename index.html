구글 드라이브에서 자동으로 가져오기

연결해 두면 드라이브 폴더에 판매현황 파일을 덮어쓰기만 하면 됩니다. 대시보드를 열 때마다 알아서 최신 파일을 받아옵니다. 구매요청 대시보드와 같은 방식입니다.

  1. script.google.com 에서 새 프로젝트 만들기
  2. 아래 📋 스크립트 복사 를 눌러 받은 코드를 붙여넣고 저장
  3. 함수 목록에서 설정 을 골라 ▷ 실행 (권한 승인) → 실행 로그에 열쇠가 나옵니다
  4. 배포 → 새 배포 → 웹 앱, 실행 계정 나 / 액세스 모든 사용자 → 배포
  5. 나온 웹 앱 URL 과 열쇠 를 아래에 붙여넣기

🔒 열쇠는 스크립트에만 있고 이 대시보드 저장소에는 없습니다. 열쇠가 없으면 주소를 알아도 데이터를 받아갈 수 없습니다.
