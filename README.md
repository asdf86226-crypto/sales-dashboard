# 판매현황 분석 대시보드

태성정밀(주) 판매현황(매출) 분석 대시보드입니다. 이카운트(ECOUNT) ERP에서 내려받은
판매현황 엑셀을 업로드하면 기간별·상품별·상품분류별·거래처별로 매출을 분석합니다.

**바로 열기 → https://asdf86226-crypto.github.io/sales-dashboard/**

---

## 저장소에는 회사 데이터가 없습니다

이 저장소는 공개(public)입니다. 그래서 **판매 실적도, 품목 분류표도, 거래처 이름도
코드에 넣지 않았습니다.** 올라가 있는 건 화면을 그리는 코드뿐입니다.

회사 데이터는 모두 **내 브라우저 안(IndexedDB)에만** 저장되고, 서버로도 이 저장소로도
전송되지 않습니다. 브라우저를 바꾸거나 사이트 데이터를 지우면 다시 올려야 합니다.

## 업데이트 방법

| 데이터 | 갱신 방식 |
| --- | --- |
| 재고현황 | 이카운트 API → 사내 PC 스크립트 → 구글시트 (매일 자동) |
| 기준데이터(품목) | 이카운트 API → 구글시트 (매일 자동) |
| **판매현황** | **이 대시보드에 엑셀 업로드 (수동)** |
| 상품분류 기준표 | 이 대시보드에 엑셀 업로드 (**처음 한 번만**) |

이카운트는 판매현황을 읽어오는 공개 API가 없어서, 판매현황만 사람이 올려야 합니다.

### 처음 한 번: 🏷 분류기준

**🏷 분류기준** 버튼으로 `분류기준.xlsx` 를 한 번 올립니다. 브라우저에 남아서
다음부터는 안 올려도 됩니다. 두 개의 시트를 읽습니다.

| 시트 | 열 |
| --- | --- |
| `상품분류` | 품목코드 · 품목명 · 상품분류 (품목코드는 비워도 됨) |
| `거래처통합` | 원래 거래처명 · 통합할 이름 (사명 변경 등, 없어도 됨) |

분류를 고치고 싶으면 그 엑셀을 고쳐서 다시 올리면 됩니다. 올리지 않아도 대시보드는
동작하지만, 품목명 키워드로만 대략 분류하므로 정확하지 않습니다. 현재 상태는 화면
위쪽 `🏷 분류기준 …건 적용 중` 줄에 표시됩니다.

### 매번: 📂 엑셀/CSV 업로드

1. 이카운트 → 판매현황 조회 → 엑셀 다운로드
2. 대시보드에서 **📂 엑셀/CSV 업로드** 클릭 후 그 파일 선택
3. 끝. 다음에 다시 열면 **올린 데이터가 그대로 남아 있습니다.**

화면 위쪽에 `💾 저장된 데이터 사용 중 · 날짜 · 파일명` 이 보이고, 옆의 **지우기**
버튼으로 언제든 삭제할 수 있습니다. 판매 데이터를 지워도 분류기준은 남습니다.

## 보고용 공유

**📤 보고용 공유** 버튼을 누르면 지금 화면 그대로를 담은 HTML 파일
(`판매현황보고_YYYYMMDD.html`)이 하나 떨어지고, 미리보기 탭이 같이 열립니다.

- 그 파일 하나만 메일/메신저로 보내면 상대방은 아무 설치 없이 열어볼 수 있습니다.
- 파일 안의 **🖨 인쇄/PDF 저장** 버튼으로 PDF로 만들 수도 있습니다.
- 현재 선택한 기간·분석기준·필터와 작성 시각이 머리글에 함께 적힙니다.

## 화면 구성

- **매출 추이** — 월/분기/연 단위, 데이터가 없는 달도 빠지지 않고 전체 기간 표시
- **상세표** — 품목코드 + 품목명, 판매량·매출(공급가액)·평균단가·비중
- **판매순위** — 전 품목(또는 전 거래처) 막대그래프, 코드 검색 → 오른쪽 상세표에서 해당 행 하이라이트
- **상품분류별 분석** — 분류 순위 + 선택한 분류 안의 품목별 상세
- **거래처별 분석** — 거래처를 고르면 그 거래처가 사간 품목 내역
- **3개월 수요 예측** — 직전 3개월 판매량·월평균, 그 앞 6개월과 비교한 3개월 필요수량 예상치
- **기간 필터** — 전체 분석 기간과, 순위/상세용 별도 기간(3개월·6개월·올해 바로가기)

## 집계 규칙

- 매출은 **공급가액(VAT 제외)** 기준입니다.
- 상품분류는 **① 품목코드+품목명 → ② 품목명 → ③ 키워드** 순으로 판정합니다.
  ①②는 올린 분류기준표에서, ③은 코드에 들어 있는 기본 규칙에서 옵니다.
- 거래처는 ㈜·(주)·주식회사·띄어쓰기를 떼고 비교하므로 표기 차이는 자동으로 묶입니다.
  사명이 아예 바뀐 경우만 분류기준의 `거래처통합` 시트에 적어주면 됩니다.

## 파일 구성

```
index.html            대시보드 본체 (단일 파일)
vendor/xlsx.min.js    엑셀 읽기 라이브러리(SheetJS mini, 로컬 사본)
.nojekyll             GitHub Pages가 파일을 그대로 서비스하게 함
```

외부 CDN을 쓰지 않으므로 사내망에서도 그대로 열립니다.
